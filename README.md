# Vanuatu Tour Booking

A simple tourism booking website for exploring tours in Vanuatu and submitting booking requests.

## Main features

- Browse four destinations: Mount Yasur, scuba diving, Mele Cascades, and land diving.
- Select a tour and enter contact details and a preferred date.
- Validate and save booking requests in the browser.
- Upload custom tour photos, saved on the device.

## Run

Open `HTML/index.html` in a web browser. Booking requests and custom photos are stored locally in that browser; bookings are requests only and are not sent to a tour provider.
